### 0.3　通用答题规范（按步骤给分）

- **建模题**：① 设变量并注明单位 → ② 写目标函数并注明 max/min → ③ 逐条列约束 → ④ 写取值范围 → ⑤ 用一句话回答原问题。缺一步扣一步分。
- **计算题**：一律**表格化**。表头写清「迭代次数 k / 区间或节点 / 关键数值 / 判据」，阅卷老师按表给分。
- **结论句**：必须同时写出「最优解」和「最优值」，并回到实际问题（如“最小成本为 6.8 元/kg”）。
- **精度**：一维搜索保留 4 位小数；线性规划顶点写成分数更稳（如 8/5 而不是 1.6）。

## 1 建立最优化数学模型

本章考「翻译」：把一段文字应用题翻译成一组数学式子。考法固定，模板固定。

### 1.1　最优化问题的一般形式与三要素

任何一个最优化问题都由**三要素**构成：决策变量、目标函数、约束条件。

```text
min（或 max）　z = f(x₁, x₂, …, xₙ)　　　　← 目标函数
s.t.　gᵢ(x₁, …, xₙ) ≤ 0,　i = 1, 2, …, m　　← 不等式约束
　　　hⱼ(x₁, …, xₙ) = 0,　j = 1, 2, …, l　　← 等式约束
　　　x ∈ D（如 x ≥ 0、x 为整数、x ∈ {0,1}）　　← 变量取值范围
```

| 要素 | 含义 | 答题要求 |
| :---: | :--- | :--- |
| 决策变量 | 可以人为安排、需要求解的量 | 逐个定义并写单位，如“x<sub>1</sub> 为甲产品产量（件）” |
| 目标函数 | 要极大或极小的指标 | 写清 max / min，且只含决策变量 |
| 约束条件 | 资源、需求、工艺等客观限制 | 每条约束对应一句题意，不重不漏 |
| 变量域 | 取值限制 | 非负、整数、0-1、上下界，一个都不能漏 |

按模型形态可分为：**线性规划**（目标与约束都是线性的）、**非线性规划**、**整数规划**（变量取整数）、**0-1 规划**（变量只取 0 或 1）。

### 1.2　建模五步法

1. **设变量**：问“要决定什么”，就设什么；单位、下标写清楚（x<sub>ij</sub> 要说明 i、j 各代表什么）。
2. **定目标**：问“追求什么”，最大写 max，最小写 min；系数是单位量的收益或成本。
3. **列约束**：把题中每句话逐一翻译成不等式或等式，左右两端量纲必须相同。
4. **补范围**：x ≥ 0；件数、人数、根数为整数；选或不选用 0-1 变量；有上下界要写上。
5. **查一遍**：数据是否都用上？约束有无重复？量纲是否一致？变量是否与目标一致？

### 1.3　题意 → 数学的语言翻译表

| 题面说法 | 数学表达 | 备注 |
| :--- | :--- | :--- |
| 至少、不低于、不少于、满足……需求 | ≥ | 最小值问题里最常见 |
| 至多、不超过、不高于、可用量为…… | ≤ | 资源约束的标准形式 |
| 恰好、正好用完、必须等于 | = | 等式约束 |
| A 与 B 产量之比不低于 2∶1 | x<sub>A</sub> ≥ 2x<sub>B</sub> | 比例约束，注意谁比谁 |
| 原材料利用率不超过 95% | 耗用量 ≤ 0.95 × 总量 | 先算总耗用再比 |
| 若选 A 则必须选 B | x<sub>A</sub> ≤ x<sub>B</sub> | 0-1 变量时的逻辑约束 |
| A、B 最多选一个 | x<sub>A</sub> + x<sub>B</sub> ≤ 1 | 互斥约束 |
| 投产批量有固定费用 | 引入 0-1 变量 y，费用 = cy | 固定成本 / 大 M 技巧 |

### 【例 1-1】生产计划问题（线性规划 · max）

某厂用钢材和工时生产甲、乙两种产品。每件甲耗钢材 2 kg、工时 2 h，获利 40 元；每件乙耗钢材 3 kg、工时 1 h，获利 30 元。现有钢材 120 kg、工时 80 h。问甲、乙各生产多少件，总利润最大？

#### 解　建模过程

① 设变量：x<sub>1</sub>、x<sub>2</sub> 分别为甲、乙产品的产量（件）。

② 目标：总利润最大，max z = 40x<sub>1</sub> + 30x<sub>2</sub>。

③ 约束：钢材、工时两种资源“不超过”可用量，故用 ≤。

④ 范围：产量非负（若按整件交货再加整数约束）。

⑤ 模型：

```text
max　z = 40x₁ + 30x₂
s.t.　2x₁ + 3x₂ ≤ 120　（钢材）
　　　2x₁ + x₂ ≤ 80　（工时）
　　　x₁ ≥ 0, x₂ ≥ 0
```

**答**：模型如上。该问题的最优解为 x<sub>1</sub> = 30，x<sub>2</sub> = 20，z<sub>max</sub> = 1800 元（求解方法见第 2 章图解法：两条资源约束同时取等号）。

### 【例 1-2】配料问题（线性规划 · min）

某养殖场配制饲料，可用甲、乙两种原料。每千克甲含蛋白质 3 单位、维生素 1 单位，价格 2 元；每千克乙含蛋白质 1 单位、维生素 2 单位，价格 3 元。每份饲料至少需要蛋白质 6 单位、维生素 4 单位。求成本最低的配方。

#### 解

① 设变量：x<sub>1</sub>、x<sub>2</sub> 分别为每份饲料中甲、乙的用量（kg）。

② 目标：min z = 2x<sub>1</sub> + 3x<sub>2</sub>。

③ 约束：营养“至少满足”，用 ≥。

```text
min　z = 2x₁ + 3x₂
s.t.　3x₁ + x₂ ≥ 6　　（蛋白质）
　　　x₁ + 2x₂ ≥ 4　　（维生素）
　　　x₁ ≥ 0, x₂ ≥ 0
```

**答**：最优解为两条营养约束的交点（x<sub>1</sub>, x<sub>2</sub>）=（1.6, 1.2），z<sub>min</sub> = 6.8 元。

> ▲ **注意 · 易错：min 问题的“方向”**
>
> - 求成本最小，但营养是“至少”（≥）——两者的方向相反是正常的，不要为了“配平”把 ≥ 改成 ≤。
> - 检验方法：把解代回每条约束，看是否满足；再随便取一个更大的点，看目标是否变差。

### 【例 1-3】下料问题（整数规划）

原料钢管每根长 6 m，需切出 2.5 m 的 60 根、1.5 m 的 100 根。现采用三种下料方案（每根 6 m 钢管）：方案Ⅰ：2.5 m × 2（余 1.0 m）；方案Ⅱ：2.5 m × 1 + 1.5 m × 2（余 0.5 m）；方案Ⅲ：1.5 m × 4（余 0）。问各方案用多少根原料钢管，使总根数最少？

#### 解

① 设变量：x<sub>1</sub>、x<sub>2</sub>、x<sub>3</sub> 分别为按方案Ⅰ、Ⅱ、Ⅲ 下料的原料钢管的根数。

② 目标：min z = x<sub>1</sub> + x<sub>2</sub> + x<sub>3</sub>（原料钢管总根数）。

③ 约束：两种规格的成品数量“不少于”需求。

```text
min　z = x₁ + x₂ + x₃
s.t.　2x₁ + x₂ ≥ 60　　　（2.5 m 的需求）
　　　2x₂ + 4x₃ ≥ 100　　（1.5 m 的需求）
　　　x₁, x₂, x₃ ≥ 0 且为整数
```

**说明**：下料问题的关键是**先枚举出所有可行下料方案**（每种方案是 6 m 内两种长度的组合），再以“方案使用次数”为决策变量。若题目要求“余料最少”，则目标改为 min z = 1.0x<sub>1</sub> + 0.5x<sub>2</sub>。

> ▲ **注意 · 易错：整数约束不能省**
>
> - 钢管根数必须是整数，若漏写“且为整数”，模型就变成线性规划，答案出现小数即不得分。

### 【例 1-4】项目投资问题（0-1 规划）

某公司有三个可投项目，投资额与三年净收益为：项目 1 需 12 万元、收益 20 万元；项目 2 需 15 万元、收益 25 万元；项目 3 需 10 万元、收益 16 万元。可用资金 27 万元，最多同时投两个项目，且项目 1 与项目 3 不能同时投。问如何选择使总收益最大？

#### 解

① 设变量：x<sub>j</sub> = 1 表示投资项目 j，x<sub>j</sub> = 0 表示不投（j = 1, 2, 3）。

```text
max　z = 20x₁ + 25x₂ + 16x₃
s.t.　12x₁ + 15x₂ + 10x₃ ≤ 27　（资金）
　　　x₁ + x₂ + x₃ ≤ 2　　　　（最多两个）
　　　x₁ + x₃ ≤ 1　　　　　　　（1 与 3 互斥）
　　　xⱼ ∈ {0, 1},　j = 1, 2, 3
```

**答**：最优方案为投资项目 1 和 2（x = (1,1,0)），最大收益 45 万元。

### 【例 1-5】运输问题（线性规划 · 产销平衡）

产地 A<sub>1</sub>、A<sub>2</sub> 的产量分别为 30、50；销地 B<sub>1</sub>、B<sub>2</sub>、B<sub>3</sub> 的需求量分别为 20、30、30。单位运价（元/吨）如下表。求总运费最小的调运方案。

|  | B<sub>1</sub> | B<sub>2</sub> | B<sub>3</sub> | 产量 |
| :--- | :--- | :--- | :--- | :--- |
| A<sub>1</sub> | 4 | 6 | 8 | 30 |
| A<sub>2</sub> | 5 | 3 | 7 | 50 |
| 需求量 | 20 | 30 | 30 | 80 |

#### 解

① 设变量：x<sub>ij</sub> 为从产地 A<sub>i</sub> 运往销地 B<sub>j</sub> 的运量（吨），i = 1,2；j = 1,2,3。

```text
min　z = 4x₁₁ + 6x₁₂ + 8x₁₃ + 5x₂₁ + 3x₂₂ + 7x₂₃
s.t.　x₁₁ + x₁₂ + x₁₃ = 30　　（A₁ 全部运出）
　　　x₂₁ + x₂₂ + x₂₃ = 50　　（A₂ 全部运出）
　　　x₁₁ + x₂₁ = 20　　　　　　（B₁ 需求满足）
　　　x₁₂ + x₂₂ = 30　　　　　　（B₂）
　　　x₁₃ + x₂₃ = 30　　　　　　（B₃）
　　　xᵢⱼ ≥ 0　(i = 1,2; j = 1,2,3)
```

**特征**：总产量 = 总需求 = 80（产销平衡），所以约束全部取等号；系数矩阵每列恰有两个 1，是运输问题的标准形式（可用表上作业法求解，本阶段只要求会建模）。

### 【例 1-6】围栏问题（非线性规划）

用长 100 m 的篱笆靠墙围一块矩形菜地（靠墙的一边不围），问长、宽各为多少时面积最大？

#### 解

① 设变量：x 为垂直于墙的边长（m），y 为平行于墙的边长（m）。

② 目标：面积最大，max S = x·y（**双线性，非线性目标**）。

```text
max　S = x y
s.t.　2x + y ≤ 100　（篱笆只围三边）
　　　x ≥ 0, y ≥ 0
```

**答**：由均值不等式 2x + y ≥ 2√(2xy) 得 xy ≤ (100)<sup>2</sup>/8 = 1250，等号在 2x = y = 50 即 x = 25 m、y = 50 m 时成立，最大面积 1250 m<sup>2</sup>。

### 1.4　建模自查清单

- 变量是否**逐个定义**并带单位？下标含义是否交代（如 x<sub>ij</sub>：i 产地、j 销地）？
- 目标函数的 max / min 是否与题意一致？系数单位是否与目标值单位一致？
- 每条约束是否都能对应到题中的一句话？有没有把“至少”写成 ≤？
- 区间、整数、0-1 等取值范围是否齐全？
- 题中给的数据是否都用上了？若某个数据没用，通常说明漏了一条约束。
- 最后是否回答了两件事：**最优解（具体方案）** 和 **最优值（数量 + 单位）**？

> ▲ **注意 · 本章最常见的三个扣分点**
>
> - ① 只写目标函数不写约束（或反过来）——建模题必须完整写出 max/min + s.t. + 变量域。
> - ② 变量没有非负约束，或整数规划漏写“为整数”。
> - ③ 目标函数方向写反：求最小成本写成 max，或把“至少满足需求”写成 ≤。

## 2 线性规划

本章两个考点：**化标准形**（纯计算，不能丢分）和**图解法**（画图 + 结论，分值最高）。二者都建立在同一个标准形式上，先把它记死。

### 2.1　线性规划的标准形式

教材采用的标准形式（max 型）为：

```text
max　z = c₁x₁ + c₂x₂ + … + cₙxₙ
s.t.　aᵢ₁x₁ + aᵢ₂x₂ + … + aᵢₙxₙ = bᵢ　(i = 1, 2, …, m)
　　　xⱼ ≥ 0　(j = 1, 2, …, n)
```

它必须同时满足**四个要求**：

| 序 | 要求 | 不满足时的典型情形 |
| :---: | :--- | :--- |
| ① | 目标函数为 max（求最大） | 题给 min z |
| ② | 全部约束为等式（=） | 题给 ≤ 或 ≥ |
| ③ | 右端常数 b<sub>i</sub> ≥ 0 | 题给 b<sub>i</sub> < 0 |
| ④ | 全部变量非负（x<sub>j</sub> ≥ 0） | 题给 x<sub>j</sub> ≤ 0 或无约束 |

若教材/课堂以 min 型为标准形，只需把“max”换成“min”，其余三条完全一样；两种标准形通过 z′ = −z 互换。

### 2.2　化标准形的六条规则

| 情形 | 处理方法 | 说明 |
| :---: | :--- | :--- |
| 目标为 min z | 令 z′ = −z，改为 max z′ = −z | 最优解不变，最优值取相反数 |
| 约束为 ≤ | 左端**加**松弛变量 x<sub>n+i</sub> ≥ 0 | 表示资源的剩余量 |
| 约束为 ≥ | 左端**减**剩余变量 x<sub>n+i</sub> ≥ 0 | 表示超出需求的部分 |
| 约束为 = | 保持不变 | 若要单纯形求解，需另加人工变量 |
| b<sub>i</sub> < 0 | 该约束两边同乘 −1 | 同时把 ≤ 与 ≥ 互换 |
| x<sub>j</sub> ≤ 0 | 令 x<sub>j</sub> = −x<sub>j</sub>′，x<sub>j</sub>′ ≥ 0 | 先换号再代回全部式子 |
| x<sub>j</sub> 无约束 | 令 x<sub>j</sub> = x<sub>j</sub>′ − x<sub>j</sub>″，x<sub>j</sub>′, x<sub>j</sub>″ ≥ 0 | 自由变量拆成两个非负变量之差 |

> ◆ **提示 · 口诀**
>
> - **min 变 max 取相反；小于加松、大于减剩；负 b 乘 −1；负变量取反，自由变量拆两半。**
> - 注意：所有替换必须**代回全部约束和目标函数**，不能只改一处。

### 【例 2-1】综合化标准形（六种情形全覆盖）

将下列线性规划化为标准形式：

```text
min　z = −3x₁ + 4x₂ − 2x₃ + 5x₄
s.t.　x₁ + x₂ + x₃ + x₄ ≤ 7
　　　x₁ − x₂ + x₃ − x₄ ≥ 2
　　　−x₁ + x₂ − x₃ + 3x₄ = −5
　　　x₁ ≥ 0,　x₂ ≤ 0,　x₃ 无约束,　x₄ ≥ 0
```

#### 解　分四步处理

1. **目标化 max**：令 z′ = −z，则 max z′ = 3x<sub>1</sub> − 4x<sub>2</sub> + 2x<sub>3</sub> − 5x<sub>4</sub>。
2. **处理负变量 x<sub>2</sub> ≤ 0**：令 x<sub>2</sub> = −x<sub>2</sub>′，x<sub>2</sub>′ ≥ 0。代入后 −4x<sub>2</sub> = 4x<sub>2</sub>′，各项含 x<sub>2</sub> 的符号全部改变。
3. **处理自由变量 x<sub>3</sub>**：令 x<sub>3</sub> = x<sub>3</sub>′ − x<sub>3</sub>″，x<sub>3</sub>′, x<sub>3</sub>″ ≥ 0。
4. **处理约束类型**：第 1 式加松弛变量 x<sub>5</sub>；第 2 式减剩余变量 x<sub>6</sub>；第 3 式两端乘 −1 使 b ≥ 0。

整理后得标准形：

```text
max　z′ = 3x₁ + 4x₂′ + 2x₃′ − 2x₃″ − 5x₄ + 0x₅ + 0x₆
s.t.　x₁ − x₂′ + x₃′ − x₃″ + x₄ + x₅ = 7
　　　x₁ + x₂′ + x₃′ − x₃″ − x₄ − x₆ = 2
　　　x₁ + x₂′ + x₃′ − x₃″ − 3x₄ = 5
　　　x₁, x₂′, x₃′, x₃″, x₄, x₅, x₆ ≥ 0
```

其中第 3 式由 (−x<sub>1</sub> + x<sub>2</sub> − x<sub>3</sub> + 3x<sub>4</sub> = −5) × (−1) 得到；又因 x<sub>2</sub> = −x<sub>2</sub>′，故 −x<sub>2</sub> 变为 +x<sub>2</sub>′。

> ■ **说明 · 为什么第 2、3 式还要加人工变量？**
>
> - 标准形只要求“等式 + 右端非负 + 变量非负”，上面已经满足。但若下一步用**单纯形法**求解，需要每个等式有一个“只在本行出现”的初始基变量：第 1 式有 x<sub>5</sub>，第 2、3 式没有，所以要补人工变量 x<sub>7</sub>, x<sub>8</sub>（大 M 法或两阶段法）。本题只要求化到标准形，不必加人工变量。

### 【例 2-2】化标准形（练习，先自己做再看答案）

将下列线性规划化为标准形式：

```text
min　z = x₁ − 2x₂ + 3x₃
s.t.　2x₁ + x₂ + 3x₃ ≤ 10
　　　x₁ − x₂ + x₃ ≥ 5
　　　x₁ ≥ 0,　x₂ 无约束,　x₃ ≤ 0
```

#### 答案

令 z′ = −z；x<sub>2</sub> = x<sub>2</sub>′ − x<sub>2</sub>″（x<sub>2</sub>′, x<sub>2</sub>″ ≥ 0）；x<sub>3</sub> = −x<sub>3</sub>′（x<sub>3</sub>′ ≥ 0），得

```text
max　z′ = −x₁ + 2x₂′ − 2x₂″ + 3x₃′
s.t.　2x₁ + x₂′ − x₂″ − 3x₃′ + x₄ = 10
　　　x₁ − x₂′ + x₂″ − x₃′ − x₅ = 5
　　　x₁, x₂′, x₂″, x₃′, x₄, x₅ ≥ 0
```

检验：原目标中 −2x<sub>2</sub> = −2(x<sub>2</sub>′ − x<sub>2</sub>″) = −2x<sub>2</sub>′ + 2x<sub>2</sub>″，取反后为 +2x<sub>2</sub>′ − 2x<sub>2</sub>″；原 3x<sub>3</sub> = −3x<sub>3</sub>′，取反后为 +3x<sub>3</sub>′。

### 2.3　图解法：五个步骤

只适用于**两个变量**的线性规划。设模型为 max z = c<sub>1</sub>x<sub>1</sub> + c<sub>2</sub>x<sub>2</sub>，s.t. 若干线性约束，x<sub>1</sub>, x<sub>2</sub> ≥ 0。

1. **建系**：以 x<sub>1</sub> 为横轴、x<sub>2</sub> 为纵轴，只画第一象限（x<sub>1</sub>, x<sub>2</sub> ≥ 0）。
2. **画边界线**：把每条约束取等号，画直线（两点定线：令 x<sub>1</sub>=0 求截距，令 x<sub>2</sub>=0 求截距）。
3. **定半平面**：取一个不在直线上的测试点（通常选原点），代入约束判断哪一侧满足，满足条件的公共部分即**可行域**。
4. **求顶点**：相邻两条边界线的交点，且必须满足其余全部约束；把可行域的所有顶点坐标列成表。
5. **平移等值线**：先画一条等值线（如 z = 0 或过原点），沿梯度方向 (c<sub>1</sub>, c<sub>2</sub>) 平移（max 向增大方向），最后离开可行域的点（或边）就是最优点；代回求 z 值并作答。

> ◆ **提示 · 最快的手算路线**
>
> - **顶点法**：把可行域所有顶点求出来，逐个代入目标函数比较大小，最大者即最优值。此法不怕斜率、不怕退化，考试最稳；等值线平移法用来解释“为什么是这一点”。

### 【例 2-3】唯一最优解

用图解法求解：

```text
max　z = 3x₁ + 5x₂
s.t.　x₁ ≤ 4
　　　2x₂ ≤ 12
　　　3x₁ + 2x₂ ≤ 18
　　　x₁, x₂ ≥ 0
```

![图 2-1　例 2-3 的可行域与等值线（虚线为 z = 36 的等值线）](optim-review/figs/fig_lp_unique.png)

#### 解

① 三条边界线分别为 x<sub>1</sub> = 4、x<sub>2</sub> = 6、3x<sub>1</sub> + 2x<sub>2</sub> = 18，均取“靠近原点”的一侧，与坐标轴围成五边形可行域 O–A–B–C–D。

② 求各顶点（相邻边界线联立）：

| 顶点 | 坐标 | z = 3x<sub>1</sub> + 5x<sub>2</sub> | 说明 |
| :---: | :---: | :---: | :--- |
| O | (0, 0) | 0 | 原点 |
| A | (4, 0) | 12 | x<sub>1</sub> = 4 与 x<sub>2</sub> = 0 |
| B | (4, 3) | 27 | x<sub>1</sub> = 4 与 3x<sub>1</sub> + 2x<sub>2</sub> = 18 |
| C | (2, 6) | **36** | 3x<sub>1</sub> + 2x<sub>2</sub> = 18 与 x<sub>2</sub> = 6 |
| D | (0, 6) | 30 | x<sub>2</sub> = 6 与 x<sub>1</sub> = 0 |

③ 比较可知 z 在顶点 C 取得最大值：

**最优解 x<sup>*</sup> = (2, 6)，最优值 z<sup>*</sup> = 36。**

④ 用等值线验证：z = 36 的等值线 3x<sub>1</sub> + 5x<sub>2</sub> = 36 恰好过点 C，再往右上平移就完全离开可行域，故 C 是最后一个接触点。

### 【例 2-4】无穷多最优解

用图解法求解：

```text
max　z = 2x₁ + 4x₂
s.t.　x₁ + 2x₂ ≤ 8
　　　x₁ ≤ 4
　　　x₂ ≤ 3
　　　x₁, x₂ ≥ 0
```

![图 2-2　例 2-4：等值线与约束边界 x<sub>1</sub> + 2x<sub>2</sub> = 8 平行，整条线段上的点都是最优解](optim-review/figs/fig_lp_multi.png)

#### 解

① 可行域为五边形，顶点为 (0,0)、(4,0)、(4,2)、(2,3)、(0,3)。

| 顶点 | (0,0) | (4,0) | (4,2) | (2,3) | (0,3) |
| :--- | :--- | :--- | :--- | :--- | :--- |
| z = 2x<sub>1</sub> + 4x<sub>2</sub> | 0 | 8 | **16** | **16** | 12 |

② 目标函数梯度 (2, 4) 与约束 x<sub>1</sub> + 2x<sub>2</sub> = 8 的法向量 (1, 2) **同向**，即等值线 2x<sub>1</sub> + 4x<sub>2</sub> = 16 与该边界**重合**，故整条线段都是最优解。

③ 结论：最优解为线段 (2,3)–(4,2) 上所有点，可写成通式

```text
(x₁, x₂) = λ(2, 3) + (1 − λ)(4, 2),　0 ≤ λ ≤ 1,
即 (x₁, x₂) = (4 − 2λ, 2 + λ)，最优值恒为 z* = 16。
```

> ◆ **提示 · 判别技巧：什么时候会“无穷多解”？**
>
> - 当目标函数等值线的斜率 −c<sub>1</sub>/c<sub>2</sub> 与某条**起作用的约束**边界斜率 −a<sub>1</sub>/a<sub>2</sub> 相等时，等值线与该边界平行；若再“贴”上去，就出现无穷多最优解，且至少有两个顶点同时最优。
> - 答题时必须写出**通式**或指出“线段上所有点”，只写一个顶点会丢分。

### 【例 2-5】无界解（有可行解但目标无界）

用图解法求解：

```text
max　z = 2x₁ + x₂
s.t.　x₁ − x₂ ≤ 2
　　　x₁ ≥ 0, x₂ ≥ 0
```

![图 2-3　例 2-5：可行域是开口向右的三角形区域，等值线可无限右移](optim-review/figs/fig_lp_unbounded.png)

#### 解

① 可行域为无界区域（三角形去掉右侧边界），它沿 x<sub>1</sub> 增大方向无限延伸。

② 取可行域内的一条射线：令 x<sub>1</sub> = 2 + t，x<sub>2</sub> = t（t ≥ 0），代入约束 x<sub>1</sub> − x<sub>2</sub> = 2 ≤ 2 恒成立，且 x ≥ 0，故整条射线都在可行域内。

③ 沿该射线目标值 z = 2(2 + t) + t = 4 + 3t → +∞（t → +∞），故目标函数无上界。

**结论：该问题无界解（无最优解）。**

> ▲ **注意 · 无界 ≠ 无可行解**
>
> - 无界解：可行域非空但无界，且目标可沿某方向无限增大（本题）。
> - 无可行解：可行域是空集（见例 2-6）。两者都“没有最优解”，但原因不同，答题要说清。

### 【例 2-6】无可行解

用图解法求解：

```text
max　z = 2x₁ + 3x₂
s.t.　x₁ + 2x₂ ≤ 4
　　　2x₁ + x₂ ≤ 3
　　　x₁ + x₂ ≥ 3
　　　x₁, x₂ ≥ 0
```

![图 2-4　例 2-6：前两个约束的交集与第三个约束的半平面不相交](optim-review/figs/fig_lp_infeasible.png)

#### 解

① 前两个“≤”约束的公共部分是三角形 (0,0)、(1.5,0)、(0,2)，其上任一点都满足 x<sub>1</sub> + x<sub>2</sub> ≤ 2。

② 第三个约束要求 x<sub>1</sub> + x<sub>2</sub> ≥ 3，与前一条矛盾，故可行域为空集。

③ 代数验证：由 x<sub>1</sub> + 2x<sub>2</sub> ≤ 4 与 x<sub>1</sub> + x<sub>2</sub> ≥ 3 相减得 x<sub>2</sub> ≤ 1，从而 x<sub>1</sub> ≥ 2；再由 2x<sub>1</sub> + x<sub>2</sub> ≤ 3 得 2x<sub>1</sub> ≤ 2，即 x<sub>1</sub> ≤ 1，矛盾。

**结论：该问题无可行解。**

### 2.4　图解法四种结果的判别

| 结果 | 图形特征 | 答题要点 |
| :---: | :--- | :--- |
| 唯一最优解 | 等值线最后与可行域**交于一个顶点** | 写出该顶点坐标与 z 值 |
| 无穷多最优解 | 等值线与某条起作用边界**平行且重合** | 写出两个端点并给出线段通式 |
| 无界解 | 可行域**无界**，且目标沿开口方向无限增大 | 指出一条射线并证明 z → ∞ |
| 无可行解 | 各半平面**无公共部分**（可行域为空） | 给出代数矛盾或用图说明 |

### 2.5　图解法练习（先画后看答案）

用图解法求解：max z = 4x<sub>1</sub> + 3x<sub>2</sub>，s.t.　x<sub>1</sub> + 2x<sub>2</sub> ≤ 8，3x<sub>1</sub> + 2x<sub>2</sub> ≤ 12，x<sub>1</sub>, x<sub>2</sub> ≥ 0。

**答案**：可行域为四边形，四个顶点及目标值如下表。

| 顶点 | (0,0) | (4,0) | (2,3) | (0,4) |
| :--- | :--- | :--- | :--- | :--- |
| z = 4x<sub>1</sub> + 3x<sub>2</sub> | 0 | 16 | **17** | 12 |

其中 (2,3) 是两条约束边界 x<sub>1</sub> + 2x<sub>2</sub> = 8 与 3x<sub>1</sub> + 2x<sub>2</sub> = 12 的交点。比较得 **x<sup>*</sup> = (2, 3)，z<sup>*</sup> = 17**。

**易错提示**：不要漏掉 (0,4) 和 (4,0) 这类“边界与坐标轴的交点”，它们也可能是最优解；本题若把目标改为 max z = 3x<sub>1</sub> + 2x<sub>2</sub>（与第二条约束平行），则 (4,0) 与 (2,3) 同时最优（z = 12），又变成无穷多最优解。

### 2.6　与后续内容的衔接（理解用，不必死记）

图解法中的“顶点”就是单纯形法中的**基本可行解**。线性规划的基本定理告诉我们：若线性规划有最优解，则**一定存在最优的基本可行解**（即最优解可在顶点处取得）。这就是“顶点法”永远有效的理论依据，也是例 2-3 中只需比较 5 个顶点的原因。

> ▲ **注意 · 图解法易错点**
>
> - ① 忘记 x<sub>1</sub>, x<sub>2</sub> ≥ 0，把可行域画到其他象限；
> - ② 半平面取反：把“≤”画成了另一侧，导致顶点全错；
> - ③ 顶点坐标算错（联立方程解错）——建议把每个顶点代回**全部**约束验算一遍；
> - ④ 平移方向搞反：max 沿梯度 (c<sub>1</sub>, c<sub>2</sub>) 方向平移，min 沿反方向；
> - ⑤ 只写“最大值 36”而不写“x = (2,6)”，答案不完整。

### 2.7　本章要点回顾与答题模板

- **标准形四件事**：目标 max、约束全为等式、右端 b ≥ 0、变量 x ≥ 0，缺一条就不是标准形。
- **化标准形六规则**：min 取反、≤ 加松弛、≥ 减剩余、= 不变、负 b 乘 −1、负变量取反 / 自由变量拆两半。
- **图解法五步**：建系 → 画线 → 定半平面 → 求顶点 → 平移等值线（或直接比较顶点值）。
- **四种结果**：唯一解（一个顶点）、无穷多解（等值线与边界重合）、无界解（可行域无界且目标无界）、无可行解（可行域为空）。

> ◆ **提示 · 图解法的答题模板（可直接照抄）**
>
> - ① 画出各约束边界线，标出可行域及其全部顶点：O(0,0)、A(…)、B(…)、…；
> - ② 列出顶点表，逐个计算目标函数值 z = c<sub>1</sub>x<sub>1</sub> + c<sub>2</sub>x<sub>2</sub>；
> - ③ 比较大小（或说明等值线斜率 −c<sub>1</sub>/c<sub>2</sub> 与哪条边界平行、最后接触哪个顶点）；
> - ④ 结论：**x<sup>*</sup> = (…)，z<sup>*</sup> = …**，并注明是唯一解 / 无穷多解 / 无界解 / 无可行解。

## 3 整数规划：分枝定界法

整数规划的难点不在“算”，而在“记录”：必须把每个子问题的松弛解、上界/下界、剪枝理由写清楚。考试就按这张“账”给分。

### 3.1　模型与分类

```text
max　z = c₁x₁ + … + cₙxₙ
s.t.　Ax ≤ b（或 =、≥）
　　　x ≥ 0，且 xⱼ 取整数（j = 1, …, n）
```

| 类型 | 要求 | 例子 |
| :---: | :--- | :--- |
| 纯整数规划 | 全部变量取整数 | 下料问题（钢管根数） |
| 混合整数规划 | 部分变量取整数 | 生产计划中“设备台数”为整数，产量可连续 |
| 0-1 规划 | 变量只取 0 或 1 | 项目投资、选址、指派 |

### 3.2　分枝定界法的四个要素

| 要素 | 做法 | 在 max 问题中的作用 |
| :---: | :--- | :--- |
| **松弛** | 先去掉整数要求，得到线性规划 LP0 | LP0 的最优值是原问题的**上界**（放宽了限制，只会更好） |
| **分枝** | 若 LP 最优解中 x<sub>j</sub> = v 非整数，则增加两个约束 x<sub>j</sub> ≤ [v] 与 x<sub>j</sub> ≥ [v] + 1，形成两个子问题 | 把原问题的整数解“分到两边”，不丢解 |
| **定界** | 当前找到的最好整数解给出**下界** z<sub>L</sub>；各子问题 LP 最优值是各自子问题的上界 | 上界 ≤ 下界的子问题不必再算 |
| **剪枝** | 满足剪枝条件的分枝不再向下搜索 | 减少计算量 |

注：[v] 表示 v 的整数部分（即向下取整，不超过 v 的最大整数），[v] + 1 即向上取整。例如 v = 4.81 时，分枝为 x<sub>j</sub> ≤ 4 与 x<sub>j</sub> ≥ 5。

### 3.3　算法步骤

1. **解松弛问题 LP0**：若 LP0 无可行解，则原问题无可行解，结束。
2. **检验整数性**：若 LP0 的最优解已全部是整数，则它就是原问题最优解，结束。
3. **分枝**：取一个非整数分量 x<sub>j</sub> = v，构造两个子问题：LP0 加上 x<sub>j</sub> ≤ [v]，LP0 加上 x<sub>j</sub> ≥ [v] + 1。分别求解。
4. **定界**：每得到一个整数解，就用它更新下界 z<sub>L</sub>（max 取较大者）；每个子问题的 LP 最优值是它的上界。
5. **剪枝**：对每个子问题，只要出现下面三种情形之一，就剪掉（不再分枝）。
6. **终止**：所有分枝都被剪掉时，当前最好整数解即最优解。

| 剪枝情形 | 判据（max 问题） | 说明 |
| :---: | :--- | :--- |
| ① 界剪枝 | 该节点 LP 最优值 ≤ 当前下界 z<sub>L</sub> | 再分下去也不会更好 |
| ② 无可行解 | 该子问题无可行解 | 说明这一支不含整数可行解 |
| ③ 整数解 | 该节点 LP 最优解已是整数 | 可作为候选解，并更新下界 |

> ◆ **提示 · min 问题要“反着看”**
>
> - 求 min 时：松弛问题的最优值是**下界**，当前最好整数解是**上界**；剪枝条件变成“该节点 LP 最优值 ≥ 当前上界”。
> - 口诀：**max 保大（上界大者优先探索），min 保小（下界小者优先探索）**。

### 【例 3-1】分枝定界法解 max 型整数规划（完整过程）

求解整数规划：

```text
max　z = 40x₁ + 90x₂
s.t.　9x₁ + 7x₂ ≤ 56
　　　7x₁ + 20x₂ ≤ 70
　　　x₁, x₂ ≥ 0 且为整数
```

#### 解

**第 1 步　解松弛问题 LP0**（去掉整数要求）：两条约束的交点

```text
9x₁ + 7x₂ = 56,　7x₁ + 20x₂ = 70　⟹　x = (4.809, 1.817),　z = 355.88
```

解非整数，需分枝。此时 上界 = 355.88，下界 = −∞（还没有整数解）。

**第 2 步　分枝**：取 x<sub>1</sub> = 4.809，分枝为 x<sub>1</sub> ≤ 4 与 x<sub>1</sub> ≥ 5。

　　LP1（x<sub>1</sub> ≤ 4）：最优解 (4, 2.1)，z = 349；（x<sub>2</sub> 仍非整数）

　　LP2（x<sub>1</sub> ≥ 5）：最优解 (5, 1.571)，z = 341.43。

**第 3 步　选上界大的 LP1 继续分枝**：取 x<sub>2</sub> = 2.1，分枝为 x<sub>2</sub> ≤ 2 与 x<sub>2</sub> ≥ 3。

　　LP3（x<sub>1</sub> ≤ 4, x<sub>2</sub> ≤ 2）：最优解 (4, 2)，**已全为整数**，z = 340　⟹　下界 z<sub>L</sub> = 340。

　　LP4（x<sub>1</sub> ≤ 4, x<sub>2</sub> ≥ 3）：最优解 (10/7, 3)，z = 327.14 < 340　⟹　**剪枝**（界剪枝）。

**第 4 步　回到 LP2**（其上界 341.43 > 340，不能剪）：取 x<sub>2</sub> = 1.571，分枝 x<sub>2</sub> ≤ 1 与 x<sub>2</sub> ≥ 2。

　　LP5（x<sub>1</sub> ≥ 5, x<sub>2</sub> ≤ 1）：最优解 (49/9, 1)，z = 307.78 < 340　⟹　**剪枝**。

　　LP6（x<sub>1</sub> ≥ 5, x<sub>2</sub> ≥ 2）：约束矛盾，**无可行解**　⟹　**剪枝**。

**第 5 步　全部剪完，结论**：

**最优解 x<sup>*</sup> = (4, 2)，最优值 z<sup>*</sup> = 340。**

### 3.4　易错点清单

- **取整方向**：x<sub>j</sub> = 4.81 时两枝是 x<sub>j</sub> ≤ 4 与 x<sub>j</sub> ≥ 5；写成 ≤ 5、≥ 4 会把非整数解又放回来。
- **界的方向**：max 时 LP 值是上界、整数解是下界；min 时正好反过来。剪枝符号（≤ / ≥）最常写错。
- **整数解不等于最优解**：找到一个整数解后还要比较其他分支的上界，只有全部剪完才能下结论。
- **剪枝要有理由**：只写“剪枝”不给判据会扣分，应写明“z = 327.14 < 340，剪枝”。
- **无可行解也是剪枝**：算不出来不等于做错，写“该子问题无可行解，剪枝”即可。
- **最后要回到原问题**：写出 x<sup>*</sup>、z<sup>*</sup>，必要时说明“取整后的实际方案”。

## 5 一维最优化（一维搜索）

一维搜索分两步走：**第一步用进退法定出含极小点的初始区间，第二步用黄金分割法把区间缩短到指定精度**。考试考的是“照表算”，要求又快又准。

### 5.1　问题形式与单峰函数

```text
min　f(x),　x ∈ R　（或 x ∈ [a, b]）
```

**单峰函数**：若存在 x<sup>*</sup> ∈ [a, b]，使 f(x) 在 [a, x<sup>*</sup>] 上严格递减、在 [x<sup>*</sup>, b] 上严格递增，则称 f 在 [a, b] 上单峰（此时极小点唯一）。

单峰性的作用：只要在一段区间内取三个点 x<sub>1</sub> < x<sub>2</sub> < x<sub>3</sub>，函数值呈“高—低—高”（f(x<sub>2</sub>) < f(x<sub>1</sub>) 且 f(x<sub>2</sub>) < f(x<sub>3</sub>)），则极小点必在 (x<sub>1</sub>, x<sub>3</sub>) 内。进退法就是去找这样的三点，黄金分割法就是不断缩小这个区间。

> ■ **说明 · 使用前提**
>
> - 两种方法都只要求 f 单峰（不要求可导），这是它们比牛顿法、抛物线法适用范围更广的原因；但若函数在区间内不是单峰，结论就不保证——答题时最好先说明“设 f 在该区间上单峰”。

### 5.2　进退法（确定初始区间）

#### 基本思想

从 x<sub>0</sub> 出发先走一步：若函数值下降，说明极小点在这个方向，就把步长加倍继续前进；一旦函数值开始上升，说明已经“跨过”极小点，最近三个点便是“高—低—高”，两端点即初始区间。若第一步函数值就上升，则说明方向选反了，应反向试探。

#### 算法步骤

1. **第 1 步**　给定初始点 x<sub>0</sub>、初始步长 h > 0，计算 f<sub>0</sub> = f(x<sub>0</sub>)；令 x<sub>1</sub> = x<sub>0</sub> + h，计算 f<sub>1</sub> = f(x<sub>1</sub>)。
2. **判断方向**：若 f<sub>1</sub> < f<sub>0</sub>，方向正确，转第 3 步；若 f<sub>1</sub> ≥ f<sub>0</sub>，令 h ← −h，重新计算 x<sub>1</sub> = x<sub>0</sub> + h 与 f<sub>1</sub>。若仍有 f<sub>1</sub> ≥ f<sub>0</sub>，则极小点在 x<sub>0</sub> 附近，区间为 [x<sub>0</sub> − |h|, x<sub>0</sub> + |h|]，停止。
3. **步长加倍**：h ← 2h，x<sub>2</sub> = x<sub>1</sub> + h，计算 f<sub>2</sub> = f(x<sub>2</sub>)。
4. **第 4 步**　若 f<sub>2</sub> < f<sub>1</sub>（仍在下降），则令 x<sub>0</sub> ← x<sub>1</sub>，f<sub>0</sub> ← f<sub>1</sub>，x<sub>1</sub> ← x<sub>2</sub>，f<sub>1</sub> ← f<sub>2</sub>，返回第 3 步。
5. **第 5 步**　若 f<sub>2</sub> ≥ f<sub>1</sub>（开始上升），停止。取三点中左右两个端点为区间端点（h > 0 时为 [x<sub>0</sub>, x<sub>2</sub>]，h < 0 时为 [x<sub>2</sub>, x<sub>0</sub>]），中间点 x<sub>1</sub> 即近似极小点。

### 【例 5-1】进退法求初始区间（前进情形）

设 f(x) = 2x<sup>2</sup> − 12x + 20，取 x<sub>0</sub> = 0，h = 1，用进退法确定初始区间。

#### 解

| k | 当前点 x<sub>k</sub> | f(x<sub>k</sub>) | 步长 h | 探测点 x<sub>k</sub>+h | f(探测点) | 判断 |
| :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| 1 | 0 | 20 | 1 | 1 | 10 | 10 < 20，方向正确，加倍前进 |
| 2 | 1 | 10 | 2 | 3 | 2 | 2 < 10，继续加倍 |
| 3 | 3 | 2 | 4 | 7 | 34 | 34 > 2，函数回升，停止 |

停止时的三点为 x<sub>0</sub> = 1、x<sub>1</sub> = 3、x<sub>2</sub> = 7，函数值 10 > 2 < 34 呈“高—低—高”，故

**初始区间 [1, 7]，x = 3 可作为近似极小点。**

验证：f′(x) = 4x − 12 = 0 得 x<sup>*</sup> = 3 ∈ (1, 7)，说明区间取对了。

### 【例 5-2】进退法（初始方向相反的“反向”情形）

设 f(x) = x<sup>2</sup> − 6x + 10，取 x<sub>0</sub> = 6，h = 1，用进退法确定初始区间。

#### 解

第一步 f(6) = 10，f(7) = 17 > 10，说明极小点**不在右侧**，必须反向试探。

| k | 当前点 | f | 步长 h | 探测点 | f(探测点) | 判断 |
| :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| 1 | 6 | 10 | +1 | 7 | 17 | 17 > 10，方向错误 → 反向 |
| 2 | 6 | 10 | −1 | 5 | 5 | 5 < 10，方向正确，加倍 |
| 3 | 5 | 5 | −2 | 3 | 1 | 1 < 5，继续加倍 |
| 4 | 3 | 1 | −4 | −1 | 17 | 17 > 1，回升，停止 |

停止时三点为 x = 5、3、−1，函数值 5 > 1 < 17，故

**初始区间 [−1, 5]，x = 3 为近似极小点。**

> ▲ **注意 · 反向情形最容易漏**
>
> - 很多同学看到 f(x<sub>0</sub>+h) > f(x<sub>0</sub>) 就停手，这是错的：这只说明“右边不是下降方向”，极小点很可能在左边。必须反向（h ← −h）再试一次。
> - 只有当左右两侧都上升（f(x<sub>0</sub>±h) ≥ f(x<sub>0</sub>)）时，才能直接取 [x<sub>0</sub>−h, x<sub>0</sub>+h]。

### 5.3　黄金分割法（0.618 法）

#### 原理：为什么是 0.618

在区间 [a, b]（长度 L = b − a）内取两点

```text
x₁ = a + (1 − λ)L,　x₂ = a + λL　(0 < λ < 1)
```

比较 f(x<sub>1</sub>) 与 f(x<sub>2</sub>)，无论舍去哪一段，新区间长度都是 λL。为了让下一次迭代**只需再算一个函数值**（另一个点可以复用），要求新点恰好是旧点，即 λ 满足

```text
λ² = 1 − λ　⟹　λ = (√5 − 1)/2 ≈ 0.618
于是 1 − λ ≈ 0.382。
```

这就是“黄金分割”：每次把区间缩短为原来的 0.618 倍，并且每轮只计算 1 个新的函数值。

#### 算法步骤

1. **第 1 步**　给定 [a, b] 与精度 ε；计算 L = b − a，取 λ = 0.618。
2. **第 2 步**　计算两个内点及其函数值：x<sub>1</sub> = a + 0.382L，x<sub>2</sub> = a + 0.618L，f<sub>1</sub> = f(x<sub>1</sub>)，f<sub>2</sub> = f(x<sub>2</sub>)。
3. **比较**：若 f<sub>1</sub> < f<sub>2</sub>，极小点在 [a, x<sub>2</sub>] 内，令 b ← x<sub>2</sub>，x<sub>2</sub> ← x<sub>1</sub>，f<sub>2</sub> ← f<sub>1</sub>，再算新点 x<sub>1</sub> = a + 0.382(b − a) 及其 f<sub>1</sub>；否则极小点在 [x<sub>1</sub>, b] 内，令 a ← x<sub>1</sub>，x<sub>1</sub> ← x<sub>2</sub>，f<sub>1</sub> ← f<sub>2</sub>，再算新点 x<sub>2</sub> = a + 0.618(b − a) 及其 f<sub>2</sub>。
4. **判停**：若 b − a ≤ ε，停止，取 x<sup>*</sup> ≈ (a + b)/2；否则返回第 3 步。

> ◆ **提示 · 手算三个要点**
>
> - ① 每轮**只有一个新点**，另一个直接沿用上一轮的值（写表时注意别重算错）。
> - ② 舍去的是**不含极小点的那一段**：f<sub>1</sub> < f<sub>2</sub> 舍右边 (x<sub>2</sub>, b]；f<sub>1</sub> > f<sub>2</sub> 舍左边 [a, x<sub>1</sub>)。
> - ③ 停止后取**中点** (a+b)/2 作为近似最优解，不要取端点。

### 5.4　精度与迭代次数

每次迭代区间长度乘 0.618，故 n 次后 L<sub>n</sub> = 0.618<sup>n</sup>L<sub>0</sub>。要求 L<sub>n</sub> ≤ ε，得

```text
n ≥ ln(ε / L₀) / ln 0.618 ≈ 2.4 × ln(L₀ / ε)
```

例：L<sub>0</sub> = 6，ε = 0.5，则 n ≥ ln(0.0833)/ln 0.618 = 5.16，故至少迭代 6 次，与例 5-3 的表一致。

计算量：第 1 轮算 2 个函数值，以后每轮 1 个，共 n + 1 个函数值——这就是黄金分割法比“每次取两个全新点”省一半计算的原因。

### 5.5　两种方法对比

| 项目 | 进退法 | 黄金分割法 |
| :---: | :--- | :--- |
| 作用 | 确定初始区间（定出“哪里有极小点”） | 在已知区间内缩短区间（“精确到多近”） |
| 前提 | 只需 f 在试探范围内单峰、无需求导 | 需要区间 [a, b] 上单峰 |
| 每步计算量 | 1 个新函数值 | 1 个新函数值（第 1 轮 2 个） |
| 停止判据 | 函数值由降转升（三点高—低—高） | b − a ≤ ε |
| 收敛速度 | 步长逐次加倍，很快跨过极小点 | 线性收敛，每轮缩为 0.618 倍 |
| 输出 | 区间 [x<sub>0</sub>, x<sub>2</sub>]，中间点为近似解 | 区间 [a, b]，中点 (a+b)/2 为近似解 |

### 5.6　易错点清单

- **漏掉反向**：f(x<sub>0</sub>+h) 上升就停手，忘了极小点可能在另一侧（见例 5-2）。
- **步长没加倍**：进退法要求 h ← 2h 再前进，写成固定步长会走成“等距扫描”，得不出正确区间。
- **区间端点写反**：区间必须写成 [小, 大]；h < 0 时三点顺序是 x<sub>2</sub> < x<sub>1</sub> < x<sub>0</sub>。
- **0.382 与 0.618 用混**：x<sub>1</sub> 靠左用 0.382，x<sub>2</sub> 靠右用 0.618。
- **重算旧点**：f<sub>1</sub> < f<sub>2</sub> 时保留的是 x<sub>1</sub>（它变成新的 x<sub>2</sub>），其函数值直接沿用。
- **判据用错**：黄金分割的停止判据是“区间长度 ≤ ε”，不是“函数值之差 ≤ ε”。
- **最后取端点**：停止后应取中点 (a + b)/2，区间端点只是界。

> ◆ **提示 · 一句话总结本章**
>
> - **进退法负责“找得到”**（用加倍步长把极小点圈起来），**黄金分割负责“算得准”**（用 0.618 反复缩小区间）。两者都只用到函数值，计算过程全部可以用表格呈现。

## 附录 B　自测题（8 题，附答案）

建议限时 40 分钟完成，再对照答案。答案中的步骤即考试应写出的过程。

#### 题 1（建模）

某厂生产 A、B 两种产品。每件 A 耗材料 3 kg、工时 4 h、利润 50 元；每件 B 耗材料 2 kg、工时 6 h、利润 40 元。现有材料 60 kg、工时 120 h。按市场要求，B 的产量不得低于 A 的 1.5 倍。试建立使总利润最大的数学模型。

**答案**：设 x<sub>1</sub>、x<sub>2</sub> 为 A、B 的产量（件），则

```text
max　z = 50x₁ + 40x₂
s.t.　3x₁ + 2x₂ ≤ 60　（材料）
　　　4x₁ + 6x₂ ≤ 120　（工时）
　　　x₂ ≥ 1.5x₁，即 1.5x₁ − x₂ ≤ 0　（比例要求）
　　　x₁ ≥ 0, x₂ ≥ 0
```

#### 题 2（化标准形）

将下列线性规划化为标准形式：

```text
min　z = 2x₁ − x₂ + x₃
s.t.　x₁ + x₂ + x₃ ≤ 8
　　　x₁ − 2x₂ + x₃ ≥ 3
　　　3x₁ + x₂ − x₃ = −2
　　　x₁ ≥ 0,　x₂ ≤ 0,　x₃ 无约束
```

**答案**：令 z′ = −z，x<sub>2</sub> = −x<sub>2</sub>′，x<sub>3</sub> = x<sub>3</sub>′ − x<sub>3</sub>″（各新变量 ≥ 0），第 3 式两端乘 −1，得

```text
max　z′ = −2x₁ − x₂′ − x₃′ + x₃″
s.t.　x₁ − x₂′ + x₃′ − x₃″ + x₄ = 8
　　　x₁ + 2x₂′ + x₃′ − x₃″ − x₅ = 3
　　　−3x₁ + x₂′ + x₃′ − x₃″ = 2
　　　x₁, x₂′, x₃′, x₃″, x₄, x₅ ≥ 0
```

注意：第 3 式乘 −1 后为 −3x<sub>1</sub> − x<sub>2</sub> + x<sub>3</sub> = 2，再把 x<sub>2</sub> = −x<sub>2</sub>′ 代入得 −3x<sub>1</sub> + x<sub>2</sub>′ + x<sub>3</sub> = 2。

#### 题 3（图解法）

用图解法求解：max z = 2x<sub>1</sub> + 3x<sub>2</sub>，s.t.　x<sub>1</sub> + x<sub>2</sub> ≤ 6，x<sub>1</sub> ≤ 4，x<sub>2</sub> ≤ 3，x<sub>1</sub>, x<sub>2</sub> ≥ 0。

**答案**：可行域为五边形，顶点及目标值：

| 顶点 | (0,0) | (4,0) | (4,2) | (3,3) | (0,3) |
| :--- | :--- | :--- | :--- | :--- | :--- |
| z | 0 | 8 | 14 | **15** | 9 |

故 **x<sup>*</sup> = (3, 3)，z<sup>*</sup> = 15**（唯一最优解）。

#### 题 4（判断解的类型，不画图说明理由）

(1)　max z = x<sub>1</sub> + x<sub>2</sub>，s.t. x<sub>1</sub> + x<sub>2</sub> ≤ 4，x<sub>1</sub>, x<sub>2</sub> ≥ 0；

(2)　max z = x<sub>1</sub> + x<sub>2</sub>，s.t. x<sub>1</sub> − x<sub>2</sub> ≥ 1，x<sub>1</sub>, x<sub>2</sub> ≥ 0；

(3)　max z = x<sub>1</sub> + x<sub>2</sub>，s.t. x<sub>1</sub> + x<sub>2</sub> ≤ 2，x<sub>1</sub> + x<sub>2</sub> ≥ 3，x<sub>1</sub>, x<sub>2</sub> ≥ 0。

**答案**：(1) 目标函数与约束边界平行，边界上所有点均为最优解，**无穷多最优解**，z<sup>*</sup> = 4；

(2) 可行域无界，且沿 x<sub>1</sub> 轴方向 z = x<sub>1</sub> → +∞，**无界解**；

(3) 两个约束互相矛盾（x<sub>1</sub> + x<sub>2</sub> 既要 ≤ 2 又要 ≥ 3），可行域为空，**无可行解**。

#### 题 5（分枝定界法，0-1 规划）

求解：max z = 6x<sub>1</sub> + 5x<sub>2</sub> + 3x<sub>3</sub>，s.t. 4x<sub>1</sub> + 3x<sub>2</sub> + 2x<sub>3</sub> ≤ 6，x<sub>j</sub> ∈ {0, 1}。

**答案**：松弛问题最优解 x = (0.75, 1, 0)，z = 9.5，需分枝。

| 节点 | 附加约束 | 松弛最优解 | z | 处理 |
| :---: | :--- | :---: | :---: | :--- |
| LP0 | — | (0.75, 1, 0) | 9.5 | 分枝 x<sub>1</sub> |
| LP1 | x<sub>1</sub> = 1 | (1, 0, 1) | **9** | 整数解，下界 = 9 |
| LP2 | x<sub>1</sub> = 0 | (0, 1, 1.5) | 9.5 | 分枝 x<sub>3</sub> |
| LP21 | x<sub>1</sub>=0, x<sub>3</sub>=0 | (0, 1, 0) | 5 | 5 < 9，剪枝 |
| LP22 | x<sub>1</sub>=0, x<sub>3</sub>=1 | (0, 1, 1) | 8 | 8 < 9，剪枝 |

故 **x<sup>*</sup> = (1, 0, 1)，z<sup>*</sup> = 9**（即选项目 1 和 3，总价值 9）。

校验：x<sub>1</sub> = 1 时约束变为 3x<sub>2</sub> + 2x<sub>3</sub> ≤ 2，取 x<sub>3</sub> = 1 得 z = 6 + 3 = 9；x<sub>1</sub> = 0 时 LP22 的最优整数解 (0,1,1) 只有 8，故最优解确为 (1,0,1)。

#### 题 6（进退法）

设 f(x) = x<sup>2</sup> − 2x + 3，取 x<sub>0</sub> = 0，h = 1，用进退法确定初始区间。

**答案**：f(0) = 3；x<sub>1</sub> = 1，f(1) = 2 < 3，方向正确；h ← 2，x<sub>2</sub> = 3，f(3) = 6 > 2，函数值回升，停止。三点 0、1、3 的函数值为 3 > 2 < 6，故

**初始区间 [0, 3]，近似极小点 x = 1。**

#### 题 7（黄金分割法）

用黄金分割法求 f(x) = x<sup>2</sup> − 6x + 10 在 [−1, 5] 上的极小点，ε = 0.6，写出前两轮迭代。

**答案**：L<sub>0</sub> = 6。

```text
第 1 轮：x₁ = −1 + 0.382×6 = 1.2918，f₁ = 3.9180；x₂ = −1 + 0.618×6 = 2.7082，f₂ = 1.0851。
f₁ > f₂ ⟹ 舍去 [a, x₁)，新区间 [1.2918, 5.0000]，保留 x₂（成为新的 x₁）。
第 2 轮：x₂ = 1.2918 + 0.618×3.7082 = 3.5836，f₂ = 1.3406（只算这 1 个新点）。
f(x₁) = 1.0851 < f₂ = 1.3406 ⟹ 舍去 (x₂, b]，新区间 [1.2918, 3.5836]，长 2.2918。
```

继续迭代至区间长 ≤ 0.6（共 5 轮），得 x<sup>*</sup> ≈ 2.9787，f ≈ 1.0005（真解 x = 3，f = 1）。

#### 题 8（简答）

分枝定界法中，一个子问题在什么情况下会被剪枝（停止分枝）？

**答案**：三种情形——

- ① **界剪枝**：该子问题松弛解的最优值不优于当前下界（max 问题为 ≤ 下界，min 问题为 ≥ 上界）；
- ② **无可行解**：该子问题本身没有可行解（约束矛盾）；
- ③ **已得整数解**：该子问题的最优解已满足整数要求，可作为候选解并更新下界，不再分枝。
